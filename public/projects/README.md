## Image Recommendations | توصيات الصور

- Use PNG or JPG format | استخدم صيغة PNG أو JPG
- Recommended size: 1200x800 pixels | الحجم الموصى به: 1200×800 بكسل
- Keep file sizes under 500KB for better performance | حافظ على أحجام الملفات أقل من 500 كيلوبايت لأداء أفضل
